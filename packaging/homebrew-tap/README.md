# MergeLane Homebrew Tap

Prebuilt [MergeLane](https://github.com/Arion-Dsh/mergelane) binaries for people collaborating through their own agents.

After the first stable release publishes `Formula/mergelane.rb`:

```sh
brew install Arion-Dsh/tap/mergelane
mergelane init
mergelane doctor
```

Upgrade with `brew upgrade Arion-Dsh/tap/mergelane`.

The formula and SHA-256 values are generated by the main repository's cargo-dist release workflow. Do not edit release URLs or checksums by hand. Each formula update runs installation checks on Apple Silicon and Intel macOS using the public release URLs.

This tap starts without a formula; installation becomes available after the first stable release. Report bugs and security issues in the main repository using its contribution and security guidance.
